FB 主页数据抓取 —— 使用说明
================================

【它做什么】
自动打开比特浏览器里的每个窗口（每个窗口是一个 FB 号），找出这个号管理的所有公共主页，
读出主页名称、14位ID、链接、关注者数，按 模板.xlsx 的格式填好，生成新的 Excel。

【第一次使用】
1. 确认电脑装了 Python（你已经装过）。
   检查方法：按 Win+R，输入 cmd 回车，在黑窗口里输入  python --version  回车，
   能看到 "Python 3.x.x" 就行。
2. 打开比特浏览器，确认 设置 -> 本地API 已开启，端口是 54348。
3. 用记事本打开 设置.txt，检查达人id等设置（默认已经填好 16185）。
4. 建议第一次只试 1~2 个窗口：在 设置.txt 里把
       只处理这些窗口序号 =
   改成例如
       只处理这些窗口序号 = 1-2
   试跑没问题后再改回空白（空白 = 全部窗口）。

【以后每次使用】
1. 打开比特浏览器（窗口不用手动打开；已经开着的也没关系，会直接接管，跑完不关）。
2. 双击 运行.bat。
   第一次运行会自动安装需要的组件，要等一两分钟。
3. 黑窗口里会显示进度。出现 "===== 完成 =====" 后按任意键关闭。
4. 结果在 输出 文件夹：
     FB数据_10-23_第1次.xlsx   ← 主表，和模板格式一模一样，只放成功的主页
     FB问题_10-23_第1次.xlsx   ← 问题表，被封号/要验证/读取失败的都在这（没问题就不生成）
   同一天再跑一次会生成 第2次、第3次，旧文件不会被覆盖。

【问题表里常见的问题类型】
  账号被限制     跳到了 checkpoint 验证页（脚本不会点 Continue，需要你自己处理）
  账号被封       页面提示账号被停用 / 暂停
  未登录         这个窗口掉登录了，手动登录一下
  窗口打开失败   比特浏览器打不开这个窗口（常见原因：代理失效）
  没找到主页     这个号下面没读到主页（可能当前处于"以主页身份"状态，手动切回个人号）
  主页不可用     主页被限制或删除
  粉丝数为约数   主页显示 1.2K 这种，没拿到精确数，主表先填了约数
  读取出错       其他意外情况
  号被封时，如果之前跑成功过，问题表会把这个号原来的主页一条条列出来（来自 输出\记录.json）。

【出问题怎么办】
  输出\日志  里有每次运行的完整过程；
  输出\调试  里有出问题时的截图和网页源码。
  把这两个文件夹里对应那次的文件打包发给开发者就行。

【中途想停】
  在黑窗口里按 Ctrl+C，已经读到的数据照样会保存成 Excel。

【文件说明】
  运行.bat       双击运行
  设置.txt       所有可以改的设置
  模板.xlsx      Excel 模板（不要改它的格式）
  main.py 等 .py 文件、requirements.txt   程序本体，不用管
